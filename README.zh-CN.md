# Vim Editing Extensions

扩展 Obsidian 内置 Vim 模式，提供自动文本对象、sandwich 风格编辑和 `gr` 寄存器替换。独立工作，不要求安装 Vimrc Support；也兼容已有 Vimrc Support 配置。

## 文本对象

| 对象 | 含义 | 示例 |
| --- | --- | --- |
| `iq` / `aq` | 自动识别双引号、单引号、反引号；内部 / 包含边界 | `viq`、`vaq`、`diq`、`daq`、`ciq`、`yiq` |
| `ib` / `ab` | 自动识别括号、引号、HTML/XML 标签；内部 / 包含边界 | `vib`、`vab`、`dib`、`cab`、`yib` |

`b` 遵循本机 sandwich 的自动包围结构行为，覆盖 `()`、`[]`、`{}`、`<>`、三种引号和标签。插件停用后，恢复 Obsidian 内置的 `b`（圆括号）。

优先选择包含光标的最内层结构，计数向外选择。例如 `v2ib`、`d2ib`。可视模式继续输入 `ib` / `ab` 可扩大到下一层。无包含光标的结构时，只在当前行向后寻找，不跨行寻找无关目标。括号和完整标签本身可以跨行；引号只在同一行匹配。

原有 `i"/a"`、`i'/a'`、`i(/a(`、`i[/a[`、`i{/a{`、`it/at` 等仍由内置 Vim 处理。

## 0.3.0 扩展对象

| 对象 | 行为 |
| --- | --- |
| `iX/aX` | 空格和 `_ , - . ; : + = ~ * / \\ \| & $` 的字面分隔片段 |
| `iL/aL` | 当前行正文／含缩进和行尾空白，不含最后的换行 |
| `iS/aS` | snake、kebab、camelCase、缩略词和数字子单词 |
| `iD/aD` | `[[双链内容]]` 内部／整体，不含前置 `!` |
| `io/ao` | 只自动识别 `()`、`[]`、`{}`；`ib/ab` 保持原有较广范围 |
| `ii/iI`、`ai/aI`、`ig/ag` | 缩进块、包含上方／上下边界、扩大到空行边界的缩进块 |
| `ik/ak`、`iv/av` | 单行键／值；支持普通正文和结构化区域 |
| `ia/aa` | 参数，跳过嵌套括号、引号和转义字符串中的逗号 |
| `if/af` | 函数调用括号内内容／调用名称及括号，不是函数定义 |
| `i?/a?` | 分两次输入左右字面边界，支持多字符，不解释正则 |
| `inX/anX`、`ilX/alX` | 下一个／上一个对象，显式跨行搜索 |

`i_` 是下划线分段，`i,` 是普通逗号分段，`ia` 才是参数；本版不注册 `i#/a#`。行内只要有一个对应分隔符，首尾片段也可选。`i` 不含分隔符，`a` 优先带右侧分隔符，末段改带左侧；连续同字符分隔符作为一个边界。

计数合并后续片段、子单词或行，嵌套对象则向外选择。可视模式重复对象只扩大选区，到边界后保持不变。`v2inq` 选第二个后续引号；普通匹配仍只在当前行向后寻找。

键值对象将 `备注: 下周处理` 也视为键值。`ik/iv` 保留键和值自身的引号，排除外围空白；`ak` 带 `:`／`=`，`av` 带行尾逗号或分号。单独的 URL、时间、比较表达式不匹配；多行值、同一行多个字段暂不支持。已知代码块／frontmatter 的行尾注释会排除，普通正文的 `#标签` 则保留。

缩进按编辑器 Tab 宽度计算，不跨代码围栏和 frontmatter 边界；零缩进以空行分块。参数和调用只做词法匹配，不承诺泛型、正则、模板插值等语言语法的完整解析。

## 对象设置

设置页提供对象组开关和标识符绑定。空标识符停用该对象；点击 **Save bindings** 后才验证并保存，重复／保留标识符会拒绝。设置变化取消未完成输入，只移除并重建插件自己的映射。

URL `L`、大写 `I/A`、整个文件 `gG` 是三个独立可选组，插件通用默认关闭。开启后，`vL/yL` 操作 URL，`vgG/ygG` 操作整个文件；普通模式的 `I/A/L` 不变。

`I` 去除内部两端空白；`A` 包含完整边界和相邻水平空白。开启大写组后，可视模式 `I/A` 等待对象标识符，`Esc` 取消；原生矩形选区插入保持不变。自定义边界的 `.` 不重新询问，正文变化或切换笔记会取消未完成输入。

设置保存在忽略的本地 `data.json`，不会进入发行文件。

## 组合键等待时间

在本插件设置中修改 **Prefix timeout (ms)** 并点击 **Apply timeout**。例如 `100` 表示等待 100 毫秒；默认 `0` 表示无限等待。仅作用于本插件暂缓的前缀：`s`、可选的可视模式 `I/A`、对象前缀后的 `n/l`，不统一接管所有 Vim 组合键或 Obsidian 快捷键。

- 在期限内匹配到组合键，继续执行。例如 `sd`／`sa` 已匹配后，后续目标、动作不再计时。
- 超时，执行软件原有的短映射一次。
- 后续键不匹配，先执行原短映射，再把后续键交给软件；未被宿主处理时继续交给原 Vim 分发器，避免吞键。
- `Esc`、切换笔记／焦点、鼠标操作、中文输入法组合、正文／选区变化、修改设置或停用插件，会取消等待，不执行过期动作。

没有自定义映射时，原生单键 `s` 会删除字符并进入插入模式；已有自定义单键映射时，则执行对应动作。插件不依赖动作所属的其他插件，也不改写 Vimrc。宿主按键转交使用合成事件，不能保证兼容要求浏览器可信事件的处理器。

## 添加、删除、替换包围符

| 操作 | 命令 | 示例 |
| --- | --- | --- |
| 添加 | `sa{motion}{符号}` | `saiw)`：`hello` → `(hello)` |
| 选区添加 | 选中文字后 `sa{符号}` | `viwsa"`：`hello` → `"hello"` |
| 删除 | `sd{符号}` | `sd"`：`"hello"` → `hello` |
| 自动删除 | `sdb` | `(hello)`、`"hello"`、`<b>hello</b>` → `hello` |
| 替换 | `sr{旧符号}{新符号}` | `sr"'`：`"hello"` → `'hello'` |
| 自动替换 | `srb{新符号}` | `srb"`：`(hello)` → `"hello"` |
| 删除标签 | `sdt` / `sdT` | `<span class="x">hello</span>` → `hello` |
| 改为普通包围符 | `srt"` | `<b>hello</b>` → `"hello"` |
| 添加标签 | `saiwt`，输入 `span class="x"` 后回车 | `hello` → `<span class="x">hello</span>` |
| 改为标签 | `sr"t`，输入标签后回车 | `"hello"` → `<span>hello</span>` |
| 选区删除 / 替换 | 完整选中包围结构后 `sd` / `sr{新符号}` | `vabsd`、`vabsr"` |

符号支持 `(`、`)`、`[`、`]`、`{`、`}`、`<`、`>`、双引号、单引号、反引号。左右括号等价，不自动增加空格。删除和替换保留内部原有空白。`t/T` 作为新包围类型时提示输入标签，两者在本插件中等价；替换标签时使用新输入的完整标签与属性。

`q` 只用于文本对象，不是 `sdq` / `srq` 的引号别名；`b` 用于自动删除／替换，不作为添加圆括号的别名。添加圆括号请使用 `saiw)`，原有 `sb` 快捷键仍保留。

## gr 寄存器替换

先用 `yiw` 复制内容，移动到目标后输入 `griw`，即可替换单词，并保留复制内容以便连续替换。

| 命令 | 行为 |
| --- | --- |
| `gr{motion}` | 替换动作覆盖的文本，例如 `grw`、`gr$` |
| `griw`、`griq`、`grib` | 替换单词、引号内或自动识别的包围内容 |
| `grr`、`2grr` | 替换当前行或两行 |
| `gr2w` | 替换两词动作覆盖的范围，只插入一份源文本 |
| 选中后 `gr` | 替换字符选区或整行选区 |
| `"agriw`、`"0griw` | 使用命名寄存器或数字寄存器；大写字母读取对应小写寄存器 |

默认读取未命名寄存器。被替换的内容不会写入删除寄存器，也不会覆盖复制内容。`u` 单步撤销、`Ctrl-r` 重做；`.` 沿用上次动作／选区尺寸和寄存器名称，并读取寄存器当时的内容。计数扩大目标范围，不重复插入源文本。

字符替换会移除行寄存器附带的一个末尾换行；整行替换保留与后续文本之间的换行，并保留目标文档末尾是否有换行。普通替换的光标落在替换起点，整行替换落在首个插入行的首个非空白字符。

本版支持未命名、字母、数字寄存器；系统剪贴板（`+`／`*`）、表达式等特殊寄存器、块寄存器、矩形选区和多光标暂不支持。空寄存器和不支持的输入会显示英文提示，正文不变。取消或替换失败不会破坏此前的 `.` 重复记录。

## 计数、取消与历史

- `2saiw)` 添加两层；`sa2w)` 把两词的 motion 结果一起包围。
- `2sd)` 删除第二层圆括号；`2srb"` 替换第二层自动识别的结构。
- 每次编辑用一次 `u` 撤销，`Ctrl-r` 重做；`.` 在当前位置重新执行上次新增的包围符操作，不复用旧坐标、不重新询问标签。普通 Vim 编辑会正常取代上次重复记录。
- `Esc` 取消未完成输入。找不到目标、无效标签、自闭合标签、输入期间切换笔记或正文改变时不执行编辑。
- 整行选区添加时将左右包围符放在独立行。删除包围符保留内容原有的换行。
- 原有 `s"`、`s'`、`s(`、`[[` 等由 Vimrc Support 继续管理，其撤销和重复行为沿用该插件。

## 启停与验证

在“设置 → 第三方插件”中启用或停用 **Vim Editing Extensions**。无需关闭内置 Vim 模式。重新加载 Vimrc：在编辑区普通模式执行 `:source .obsidian.vimrc` 后回车。

命令面板的 **Vim Editing Extensions: Run compatibility checks (temporary note)** 会创建一次性测试笔记，在源码模式和实时预览模式中输入测试命令，写入本插件目录的 `validation.json`，然后将测试笔记移入 Vault 回收站并恢复原标签页和测试使用的 Vim 寄存器。它不会重新加载或改写 Vimrc。不会编辑现有笔记。

开发：

```sh
npm ci
npm test
npm run build
```

测试包含纯文本匹配及真实 Vim 引擎的按键、选区、寄存器、历史和启停行为。默认测试使用公共的 CodeMirror Vim 引擎，可在 CI 中执行。macOS 可运行 `npm run test:obsidian`，从本机最新 Obsidian 更新包读取实际引擎；或设置 `OBSIDIAN_VIM_RUNTIME` 指向相应 `vim.js`。发行包不包含 Obsidian 引擎。

## 当前版本边界

适用于桌面版 Obsidian 1.14.5 及以上，实际验证版本记录在 `validation.json`。依赖非公开的 `CodeMirrorAdapter.Vim` 接口；能力检查失败时不注册扩展映射，并显示英文诊断。

不支持矩形选区编辑、多光标、宏、折叠／视口／诊断对象及完整 Vim 插件移植；保留原生矩形插入。匹配基于 Markdown 源文本，不执行 HTML，不依赖语言语法树。

启用时 `s` 作为多键命令前缀；停用时恢复原有单键 `s` 映射。公开项目使用 MIT 许可证，不包含个人 Vault 配置。
